# Full System Flow (How Everything Connects)
Game.exe
   |
   |  (DLL injection)
   v
ScalerMiddleware.dll
   |
   |-- DllMain → HookManager → GraphicsBackend
   |
   |-- GraphicsBackend intercepts Present()
   |
   |-- ScalerManager.Dispatch() applies FSR/XeSS
   |
   |-- GraphicsBackend.SubmitUpscaledFrame()
   |
   |-- Frame goes to encoder → stream to user
   |
   |-- IPCServer listens for scaler changes
